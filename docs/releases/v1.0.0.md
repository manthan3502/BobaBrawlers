# Boba Brawlers v1.0.0 — release draft

**Status: prepared locally; not tagged, uploaded or published. Public Windows release is blocked pending permission for the supplied reaction recording.**

## The game

Small Pearls. Big Brawls. A Windows single-player arcade brawler built in Unity 6000.6.6f1 with URP and C#.

- Three distinct playable 3D fighters: Boba Bruiser, Mango Mayhem and Matcha Ninja, with equal combat statistics and saved selection.
- Directional movement and hold/release charged dash; physical knockback, a real central hole and outer-edge ring-outs.
- Three rounds: First Sip (1 rival / 2 KOs / 90 s), Sugar Rush (2 / 3 / 90 s) and Final Brawl (3 / 5 / 100 s).
- Telegraphed AI attacks, safe respawns, three hearts, progression, local best scores and streaks.
- Live model previews, responsive HUD/menus, pause/settings, full-charge feedback, trails, impacts and victory presentation.
- Original music/effects; local player falls use the exact supplied FAHHH recording with music ducking and final-heart continuity.

## Install and play

When a release is approved, download its Windows ZIP, **extract the entire folder**, and run `BobaBrawlers.exe`. Keep the data folders and DLLs together. Unity is not required on the player's computer.

WASD/arrows move and aim. Hold Space to charge; release to dash. Escape pauses/resumes. Reach the KO target before time or hearts run out. Win to unlock the next round.
